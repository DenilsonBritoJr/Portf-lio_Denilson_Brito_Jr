## Portfólio profissional - Software Development

## 🎓 Sobre o Projeto 

Este repositório contém o **Portólio**, um projeto de cunho não apenas acadêmico, mas também visando o nicho profisional desenvolvido por **Denilson Brito Junior**, estudante do 1º semestre do curso de Desenvolvimento de Software Multiplataforma (DSM) na FATEC


## OBJETIVO
OBJETIVO
Escopo: Desenvolver um portfólio web responsivo focado em navegação intuitiva. A plataforma incluirá:

    Páginas e Seções: Página index projetos-api, trajetoria e Contato;

    Navegação: Barra de navegação centralizando os acessos;

    Funcionalidade: Botão de acesso direto ao currículo.



## Branding visual
O roxo foi uma escolha vinculada ao estratégica que transmite criatividade, sofisticação, luxo, sabedoria e inovação
